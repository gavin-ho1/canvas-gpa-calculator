Install the extension

Free on all three stores. Same extension, same features.

Chrome Chrome Web Store Edge Microsoft Edge Add-ons Firefox Firefox Add-ons

Using Brave, Arc, Opera, or another Chromium browser? Use the Chrome version.

After installing

  1. Open Canvas and go to your dashboard or any course's Grades page.
  2. Your calculated grade appears on the page. If it doesn't, click the extension icon and make sure Enable Extension is on.

Having trouble?

Check the issues on GitHub. If nobody has reported your problem yet, open a new issue and include your browser and what you see on the page.
